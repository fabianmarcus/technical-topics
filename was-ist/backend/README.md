# Backend

Das Backend ist der Teil einer Anwendung, der Daten verarbeitet, Geschäftslogik ausführt und Schnittstellen für andere Systeme bereitstellt. Es läuft typischerweise serverseitig und bildet die technische Grundlage für Frontend, Integrationen und Automatisierungen.

In dieser Sektion sammle ich Begriffe und Technologien, die mir bei der Arbeit mit Backend-Systemen begegnen.
